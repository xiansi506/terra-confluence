# 从源码构建

[返回项目首页](../README.md)

使用 **JDK 17** 和仓库自带的 Gradle Wrapper。首次运行需要下载 Gradle、Forge 和 Minecraft 映射。

## 准备本地构建依赖

下载以下 Minecraft 1.20.1 Forge JAR，放在仓库根目录的 `libs/` 下，并按表格重命名。`libs/` 是本地依赖目录。

| 依赖 | 版本 | 文件名 |
| --- | --- | --- |
| [Botania](https://modrinth.com/mod/botania/versions?g=1.20.1&l=forge) | 1.20.1-455 Forge | `Botania-1.20.1.jar` |
| [Patchouli](https://modrinth.com/mod/patchouli/version/1.20.1-83-forge) | 1.20.1-83 Forge | `Patchouli-1.20.1-83.jar` |
| [JEI](https://maven.blamejared.com/mezz/jei/jei-1.20.1-forge/15.49.0.188/) | 15.49.0.188 Forge | `jei-15.49.jar` |
| [KubeJS](https://modrinth.com/mod/kubejs/version/2001.6.5-build.26%2Bforge) | 2001.6.5-build.26 Forge | `kubejs-1.20.1.jar` |

`gradle.properties` 的 `use_local_deps` 应为 `true`。

## 编译

Windows PowerShell

```powershell
.\gradlew.bat build
```

Linux 或 macOS

```sh
./gradlew build
```

可安装的成品位于 `build/libs/terra-confluence-1.0.20.jar`。依赖和映射已缓存时，可以给命令加 `--offline`。

要在游戏里试用，把成品装进 Forge 1.20.1 测试实例，并按[安装说明](使用教程.md#安装)补齐运行依赖。
